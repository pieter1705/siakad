# SIAKAD - Student Academic Information System

Sistem informasi akademik untuk FKIP Universitas Pattimura. Dibuat dengan PHP Native + MySQL.

## Features
- Data mahasiswa, dosen, mata kuliah
- Input & lihat nilai KHS 
- Panel admin untuk CRUD data
- Login multi-role: Admin, Dosen, Mahasiswa

## Tech Stack
- PHP 8.x
- MySQL
- Bootstrap 5
- XAMPP

## Cara Install
1. Clone repo ini ke htdocs: `git clone https://github.com/pieter1705/siakad`
2. Import database `siakad.sql` ke phpMyAdmin
3. Edit `config/database.php` sesuai user MySQL lu
4. Jalankan di browser: `localhost/siakad`
